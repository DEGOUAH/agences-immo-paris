# Agences Immobilières Paris

Répertoire de 186 agences immobilières à Paris (du 1er au 20e arrondissement), avec adresse, note Google, téléphone, site web et lien Maps — pour candidater directement auprès des agences.

## Fichiers

- `dashboard.html` — page autonome (aucun serveur requis). Ouvre-la directement dans un navigateur.
- `agences.json` — données brutes structurées.
- `build_data.py` — script Python utilisé pour générer `agences.json` à partir des extractions Google Maps.

## Utilisation

Ouvre simplement `dashboard.html` dans ton navigateur. Filtre par arrondissement, cherche par nom/rue, trie par note, et coche les agences déjà contactées (suivi conservé localement dans le navigateur).

## Source des données

Extraites de Google Maps en août 2026.
